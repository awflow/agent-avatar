## Shared global constraints (every plan)

- Repo root: `awflow-agant-avatar/` (bun workspaces + Turborepo + Biome + TypeScript, mirroring Peek). Core tests: `bun test`. Framework adapters: vitest.
- The core package (`packages/avatar`) has **zero runtime dependencies** and never touches the DOM outside `animate.ts`/`mount.ts`.
- Determinism: same input → same SVG bytes on server and client. `peek@1` output is byte-identical to `@doan-labs/peek` 1.2.0 (Peek commit `0f5c4ff9565e698167c5108341bb6ab8ff3ab441`).
- Lists are append-only and ordered; any change that alters an existing name's output under a released version requires a new version.
- Animation: one shared rAF loop, DOM attribute writes only, paused off-screen, `prefers-reduced-motion` cuts durations, never the pose.
- MIT; LICENSE carries Doan Labs' and AWFlow's copyright lines; README/docs credit "Built on Peek by Doan Labs". Never use the Doan Labs name/mark as branding; always "Doan Labs", never "Doan" alone.
- Commit after every task. No pushing/publishing until Plan 6 (the npm org `awflow` must be created by the owner first).
